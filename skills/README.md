# Grok Bot のスキル

ここにあるフォルダ1つが、Grok Bot のスキル1つです。使いたいスキルのフォルダ（または中の `SKILL.md`）を、自分の Grok Bot に渡してください。

- `nounai-card/`：脳内会議の結果から、会議の前と後を並べたカードを作る

## 脳内会議のキャラ（1体＝1つのBot）

遠藤さんの「17 キャラ別ルール（スキル化）」の別Bot用指示文（per-bot、2026-10-11 14:59 JST 更新版）を、キャラごとにそのまま入れています。入れ方はリポジトリの README の「自分のGrok Botにキャラを入れる方法」を見てください。貼る部分だけは各フォルダの `paste.txt` にあります。

| フォルダ | キャラ | 出番 |
|---|---|---|
| `議長/` | 議長 | 進行・割合JSON・脳内もちつき・まとめ・安全ガード |
| `感情/` | 感情 | 割合JSONの「発言するキャラ」にいるとき |
| `理性/` | 理性 | 割合JSONの「発言するキャラ」にいるとき |
| `不安/` | 不安 | 割合JSONの「発言するキャラ」にいるとき |
| `愛/` | 愛 | 割合JSONの「発言するキャラ」にいるとき、もちつきの合図 |
| `めんどくさい/` | めんどくさい | 割合JSONの「発言するキャラ」にいるとき |
| `ボケ/` | ボケ | 「ボケを出す」が true のときだけ、1会議で1回 |
| `ツッコミ/` | ツッコミ | 「ツッコむ相手」に1回、ボケには必ず1回、もちつきの合図 |
| `ミライ/` | ミライ（控え） | 議長が脳内もちつきで呼んだときだけ |
